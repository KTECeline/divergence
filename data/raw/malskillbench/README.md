# MalSkillBench (raw)

Place the **unmodified** MalSkillBench dataset (Guo et al., 2026) in this folder.

Expected contents (per the paper):
- 3,944 malicious + 4,000 benign agent skill samples
- Three-dimensional taxonomy labels: attack vector (Code Injection / Prompt Injection / Mixed)
  × behaviour class × insertion strategy (108 cells)

Do not edit files here — all processing output goes to `data/processed/`.
